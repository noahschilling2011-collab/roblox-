# 🚀 So bringst du Planet Forge auf Roblox – Schritt für Schritt

Diese Anleitung ist extra einfach geschrieben. Wenn du jeden Schritt der Reihe
nach machst, ist dein Spiel am Ende **echt auf Roblox** und deine Freunde
können es spielen. Du brauchst: einen Computer, Internet und ein
Roblox-Konto (das du zum Spielen sowieso schon hast).

---

## Schritt 1: Roblox Studio holen 🧰

Roblox Studio ist das kostenlose Bau-Programm von Roblox. Damit macht man
Roblox-Spiele.

1. Öffne im Internet-Browser diese Seite: **https://create.roblox.com**
2. Klicke auf den großen Knopf **„Start Creating"** (auf Deutsch: „Jetzt erstellen").
3. Die Datei lädt herunter. Klicke sie doppelt an und installiere sie
   (immer auf „Weiter" / „OK" klicken).
4. Öffne Roblox Studio und **melde dich mit deinem Roblox-Konto an** –
   mit demselben Namen und Passwort, mit dem du auch Roblox spielst.

✅ Geschafft, wenn: Roblox Studio offen ist und du angemeldet bist.

---

## Schritt 2: Die Spieldatei herunterladen 💾

Das ganze Spiel steckt fertig in **einer einzigen Datei**: `PlanetForge.rbxlx`.

1. Öffne die Projektseite: **https://github.com/noahschilling2011-collab/roblox-**
2. Klicke in der Dateiliste auf **`PlanetForge.rbxlx`**.
3. Klicke oben rechts auf den **Download-Knopf** (ein Pfeil nach unten ⬇,
   er heißt „Download raw file").
4. Merke dir, wo die Datei landet (meistens im Ordner **„Downloads"**).

✅ Geschafft, wenn: Die Datei `PlanetForge.rbxlx` auf deinem Computer ist.

---

## Schritt 3: Das Spiel in Roblox Studio öffnen 🌍

1. Gehe in deinen **Downloads-Ordner**.
2. Mache einen **Doppelklick** auf `PlanetForge.rbxlx`.
3. Roblox Studio öffnet sich – und dein Spiel ist drin!

Falls der Doppelklick nicht klappt: Öffne Roblox Studio, klicke oben links auf
**FILE → Open from File** und wähle die Datei aus.

✅ Geschafft, wenn: Studio offen ist und links im Fenster „Explorer" Sachen wie
`ServerScriptService → Server` stehen.

---

## Schritt 4: Einmal Probespielen ▶️

1. Drücke oben in der Mitte auf den blauen **Play-Knopf** ▶ (oder Taste F5).
2. Du startest auf einer Plattform und wirst auf **deinen Planeten** gebracht.
3. Probiere aus:
   - **„Energie sammeln"** drücken → du bekommst Energie ⚡
   - Links **„Biome"** aufklappen → eine **Wiese** kaufen 🌿
   - **„Fund suchen (25)"** → du findest ein Sammelobjekt 🎁
   - Oben links **„✏️ Planet benennen"** → gib deinem Planeten einen Namen
   - Rechts **„🏆 Rangliste"** und **„🛒 Shop"** anschauen
4. Schau unten ins Fenster **„Output"**: Dort sollte stehen:
   `[PlanetForge] Selbsttest bestanden` – das heißt, alles funktioniert. ✅
5. Zum Aufhören: oben auf das rote **Stopp-Quadrat** ⏹ drücken.

> ⚠️ Beim Probespielen wird dein Fortschritt noch **nicht gespeichert**.
> Das schalten wir in Schritt 6 ein – dafür muss das Spiel erst
> veröffentlicht sein.

---

## Schritt 5: Das Spiel auf Roblox hochladen ⬆️

Jetzt kommt das Spiel wirklich auf Roblox:

1. Klicke oben links auf **FILE → Publish to Roblox**
   (auf Deutsch: „Auf Roblox veröffentlichen").
2. Ein Fenster geht auf. Trage ein:
   - **Name:** `Planet Forge`
   - **Beschreibung:** z. B. „Baue deinen eigenen Planeten, sammle seltene
     Schätze und besuche deine Freunde!"
3. Klicke unten auf **Create** (Erstellen).
4. Kurz warten … fertig! Dein Spiel liegt jetzt auf deinem Roblox-Konto.

✅ Geschafft, wenn: Unten rechts „erfolgreich veröffentlicht" erscheint.

---

## Schritt 6: Das Speichern einschalten 💾⚡

Damit sich das Spiel die Planeten der Spieler **merkt** (auch nach dem
Ausschalten), musst du einen Schalter umlegen:

1. Klicke in Studio oben auf **HOME → Game Settings** (Zahnrad-Symbol ⚙).
2. Klicke links auf **Security** (Sicherheit).
3. Schalte **„Enable Studio Access to API Services"** auf **AN** (grün).
4. Klicke auf **Save** (Speichern).

✅ Geschafft, wenn: Der Schalter grün ist. Ab jetzt wird jeder Planet gespeichert.

---

## Schritt 7: Das Spiel für alle freigeben 🌐

Gerade kannst nur **du** das Spiel sehen. So dürfen es alle spielen:

1. Öffne wieder **HOME → Game Settings** ⚙.
2. Klicke links auf **Permissions** (Berechtigungen).
3. Wähle **Public** (Öffentlich) aus.
4. Klicke auf **Save**.

✅ Geschafft, wenn: Bei Permissions „Public" ausgewählt ist.

---

## Schritt 8: Spielen und Freunde einladen! 🎉

1. Gehe im Browser auf **https://create.roblox.com** und klicke auf
   **Creations** (Kreationen) – da ist dein Spiel!
2. Klicke es an und dann auf den Namen – so kommst du zur Spielseite
   auf roblox.com.
3. Drücke den grünen **Play-Knopf** – du spielst dein eigenes Spiel! 🥳
4. **Kopiere den Link** der Spielseite und schicke ihn deinen Freunden.
   Wenn ihr zusammen im Spiel seid, könnt ihr euch **besuchen, liken und
   handeln**.

---

## Extra (später): Den Robux-Shop scharf schalten 🛒

Der Shop im Spiel zeigt am Anfang überall „Bald…" an. Das ist Absicht:
Du musst die Produkte einmal bei Roblox anlegen.

1. Gehe auf **https://create.roblox.com** → dein Spiel anklicken.
2. Links im Menü: **Monetization → Passes** – lege 3 Gamepässe an:
   „Kosmische Sammlung", „Wettermeister", „Haustier-Freund".
3. Links im Menü: **Monetization → Developer Products** – lege 4 Produkte an:
   „Goldener Kern", „Lava-Kern", „Eiskern", „Regenbogen-Aura".
4. Jedes Produkt bekommt von Roblox eine **Nummer (ID)**.
5. Öffne in Studio im Explorer:
   `ReplicatedStorage → Shared → Config → MonetizationConfig` und trage die
   Nummern dort ein, wo jetzt `= 0` steht (die Namen stehen direkt daneben).
6. Nochmal **FILE → Publish to Roblox** → fertig, der Shop verkauft echte
   Kosmetik für Robux!

Mehr Details dazu: [Monetarisierung](MONETARISIERUNG.md), Abschnitt 8.

---

## Wenn etwas nicht klappt 🔧

| Problem | Lösung |
|---|---|
| Doppelklick öffnet Studio nicht | Studio öffnen → FILE → „Open from File" → Datei auswählen |
| „Selbsttest" steht nicht im Output | Output-Fenster einschalten: VIEW → Output |
| Fortschritt wird nicht gespeichert | Schritt 5 (veröffentlichen) und Schritt 6 (API-Schalter) prüfen |
| Freunde finden das Spiel nicht | Schritt 7 prüfen: Permissions muss auf „Public" stehen |
| Shop zeigt nur „Bald…" | Das ist normal, bis du den Extra-Teil oben gemacht hast |

Viel Spaß beim Bauen deiner Planeten-Welt! 🌍✨
